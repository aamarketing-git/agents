# 왜 필요했나

"거절 문장 하나를 미리 외워두세요" 까지만 말하면,
읽는 사람은 **정작 무슨 문장을 외워야 하는지** 모릅니다.
방향은 알겠는데 손이 안 움직이는 겁니다.

그래서 방향을 제시하는 문장마다 **그대로 따라 할 수 있는 예시**를 붙였습니다.

| 조언 | 붙은 예시 |
|---|---|
| 거절 문장 하나를 미리 외워두세요 | "지금은 일정이 차 있어서 어렵습니다. 다음에 기회가 되면 제가 먼저 연락드릴게요." 이유를 길게 달면 파고들 틈이 생기니 한 문장에서 끊으세요 |
| 레버리지를 하나 거세요 | 1:1로 하던 것을 1:다로 바꾸는 것이 레버리지입니다. 개인 수업을 녹화해 다섯 명에게 같이 팔아 보세요 |
| 비중을 숫자로 정해두세요 | 달력에 요일로 박으세요. '월·수·금은 만들기, 화·목은 가르치기' 같은 식입니다 |
| 속도를 줄이세요 | 결제 버튼 앞에서 하루 재우는 규칙을 만드세요. 장바구니에 담아 두고 다음 날 아침에 다시 보면 절반은 안 삽니다 |
| 어디까지가 내 일인지 문서로 못 박고 들어가세요 | 견적서 맨 아래에 세 줄. '포함: ○○ / 불포함: ○○ / 수정 2회, 이후 건당 ○원' |
| 결론보다 이유를 먼저 말하는 순서를 지키세요 | "이건 안 됩니다"가 아니라 "일정이 ○일밖에 없어서, 이건 어렵습니다"로 말하세요 |
| 내가 없어도 하루가 돌아가는지 확인하세요 | 분기에 하루, 연락을 끊고 빠져 보세요. 그날 전화가 몇 번 왔는지 적으면 그게 아직 나한테만 묶인 일의 목록입니다 |

## 범위

처음에는 '~하세요'로 끝나는 문장만 찾았는데, 말씀대로 **방향을 제시하는 문장 전부**로 넓혔습니다.

- `~하세요` / `~두세요` / `~마세요`
- `~하는 편이 낫습니다` / `~쪽이 맞습니다` / `~유리합니다` / `~안전합니다`
- `~해야 합니다` / `~하셔야 합니다` / `~필요합니다`
- `~구조가 맞습니다` / `~방식이 맞습니다` / `~로 가야 오래갑니다`

전수 조사해 보니 **308종**이 나왔고, 그중 상위 151종이 전체 노출의 92%였습니다.
거기에 맞춰 **키 150개 / 예시 300문장**을 썼습니다.

## 화면

풀이 아래에 금색 테두리의 **'예를 들면'** 칸이 생깁니다.
기존 '이렇게 봤습니다'(근거)·'해보실 것'(처방)과 구분되도록 테두리와 색을 달리했습니다.

한 항목에 최대 2개까지만 붙습니다. 많이 붙이면 오히려 안 읽힙니다.

# 검증

예시 검사를 `scan.mjs` 에 넣었습니다. 세 가지를 봅니다.

1. **적용률** — 조언이 들어 있는 항목에 예시가 붙었는가
2. **사전 무결성** — 키 중복, 너무 짧은 키, 빈 예시, 3개 이상 붙는 경우
3. **구체성** — 예시 짝마다 적어도 하나는 손에 잡히는 것인가
   (숫자·실제 문장·요일·달력·통장·계약서 같은 가리킬 수 있는 것)

| 검사 | 범위 | 결과 |
|---|---|---|
| 예시 적용률 | 항목 2,160개 (조언 있는 항목 1,172 / 서술만 있는 항목 988) | **100%** · 빠짐 0 |
| 예시 사전 | 키 150개 · 예시 300문장 | 오류 0건 |
| 성별·대운 | 666건 | 오류 0건 |
| 음력 입력 | 563건 + 윤달 8건 | 오류 0건 |
| 엔진 기본 | 절기·진태양시·60갑자 73,000일 | 33 / 33 통과 |
| 신살 전수 | 명식 1,638개 | 오류 0건 |
| 직업 전수 | 명식 56개 × 직업 69개 | 오류 0건 |
| 전체 스캔 | 명식 1,560개 · 문장 167만 개 | 오류 0건 |
| 화면 동작(jsdom) | 전 갈래 + 연인·2~5인 궁합 | 전부 통과 |

서술만 있는 항목(배우자 성격, 돈 그릇 크기 같은)에는 예시를 붙이지 않았습니다.
조언이 없는 곳에 예시를 붙이면 군더더기가 됩니다.

```bash
node scan.mjs      # 전수 + 직업 + 신살 + 음력 + 성별·대운 + 예시
node test.mjs      # 엔진 기본 33가지
node dupcheck.mjs  # 카테고리 사이 중복
python3 build.py public/manse.html
```

# 예시를 더 넣거나 고치려면

`engine/examples.js` 한 파일만 보시면 됩니다.

```js
{ k:"풀이 글에 실제로 들어 있는 조각",
  ex:["예시 1", "예시 2"] },
```

`k` 는 풀이 본문에 그대로 들어 있는 문구입니다. 이 문구가 보이면 예시가 붙습니다.
짧게 잡으면 엉뚱한 데 걸리니 8자 이상으로 잡으시는 편이 안전하고,
추가한 뒤 `node scan.mjs` 를 돌리면 적용률과 구체성을 바로 확인할 수 있습니다.
