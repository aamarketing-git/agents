# 미네랄 영상 나레이션 프롬프트 (15초)

## TTS / 성우용 프롬프트
```
차분하고 신뢰감 있는 30대 여성 내레이터, 건강·교양 다큐멘터리 톤.
또렷한 표준어 발음, 보통보다 약간 빠른 속도(약 1.1배), 문장 사이 짧은 쉼.
마지막 문장 "균형 잡힌 식사가 중요합니다."는 한 박자 쉬고 따뜻하게 강조.
총 길이 14~15초 이내.
```

## 전체 원고 (한 번에 붙여넣기용)
미네랄은 암석과 토양에서 비롯된 무기질 영양소입니다. 채소와 곡물, 견과류, 그리고 물을 통해 섭취하죠. 뼈와 치아를 만들고, 혈액과 근육, 신경이 제 기능을 하도록 돕습니다. 부족하면 피로와 빈혈, 근육 경련이 생길 수 있어요. 균형 잡힌 식사가 중요합니다.
