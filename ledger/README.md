# 가계부 (영수증·결제 문자 → 자동 분류 → 구글 시트 정산)

지출이 생길 때 **영수증 사진을 찍거나, 결제 문자/알림을 공유**하면 AI와 규칙이 읽어서 자동으로 분류합니다.
모든 내역은 **구글 시트**에 쌓이고, **주간·월간 정산은 엑셀처럼 수식으로** 자동 계산됩니다.
수입은 **정기수입 / 비정기수입** 두 가지로 나눕니다.

```
 폰(PWA 앱) ──영수증 사진·문자·직접입력──▶ Apps Script(웹앱) ──▶ 구글 시트
   ▲ 오프라인에서도 저장(나중에 전송)         │  규칙 분류 → 모르면 AI(Claude)      ├ 거래내역   (원본 한 줄씩)
   └──────────── 내역·정산 화면 ◀───────────┘  정기수입 매월 자동 등록            ├ 주간정산   (최근 12주, 월~일)
                                                                                  ├ 월간정산   (최근 12개월 + 차트)
                                                                                  └ 카테고리 · 분류규칙 · 정기수입
```

## 폴더 구조

| 경로 | 설명 |
|---|---|
| `pwa/` | 모바일 웹앱(빌드 없는 정적 파일). 홈 화면에 추가하면 앱처럼 동작 |
| `apps-script/Code.gs`, `Core.gs` | 구글 시트에 붙이는 백엔드 (저장·조회·AI 인식·정기수입) |
| `core/core.js` | 앱과 백엔드가 **함께 쓰는** 문자 파싱·자동 분류·집계 로직 (원본) |
| `scripts/` | `sync-core.mjs`(원본 복사), `make-icons.mjs`, `e2e.mjs`(브라우저 테스트) |

## 설치 (약 10분)

### 1. 구글 시트 + 백엔드
1. 새 구글 스프레드시트를 만듭니다.
2. **확장 프로그램 → Apps Script** 를 열고, `apps-script/Code.gs` 내용을 `Code.gs` 에, `apps-script/Core.gs` 내용을 새 파일 `Core.gs` 에 붙여넣습니다.
3. 시트로 돌아와 새로고침하면 **가계부** 메뉴가 생깁니다 → **① 초기 설정** 실행(권한 허용). 탭이 만들어지고 **연결 토큰**이 표시됩니다.
4. Apps Script에서 **배포 → 새 배포 → 웹 앱** : 실행 사용자 `나`, 액세스 `모든 사용자` → 나오는 **웹 앱 URL**을 복사합니다. (토큰이 없으면 아무것도 읽거나 쓸 수 없습니다.)
5. (영수증 사진 인식을 쓰려면) **프로젝트 설정 → 스크립트 속성** 에 `ANTHROPIC_API_KEY` 추가. 모델은 기본 `claude-haiku-5-5`, 바꾸려면 `CLAUDE_MODEL` 속성을 추가합니다.
   키가 없어도 결제 문자 입력·자동 분류(규칙)·정산은 모두 동작합니다.

### 2. 앱
`pwa/` 폴더를 정적 호스팅(GitHub Pages, Vercel, Netlify 등)에 올리거나 로컬에서 확인합니다.

```bash
cd ledger/pwa && python3 -m http.server 8080   # http://localhost:8080
```

폰 브라우저로 주소를 열고 **홈 화면에 추가** → 앱 **설정 탭**에 웹 앱 URL과 토큰 입력 → *저장하고 연결 확인*.
(안드로이드에서는 설치 후 문자앱의 **공유 → 가계부**로 결제 문자를 바로 보낼 수 있습니다.)

## 사용법

- **영수증 찍기** : 사진 → AI가 상호·날짜·금액·결제수단·품목을 읽고 분류 → 확인 화면에서 **저장** 한 번.
- **결제 문자 붙여넣기 / 공유** : 카드 승인·취소, 은행 입금·출금 문자를 읽습니다. 승인취소는 마이너스 지출로 기록돼 정산에서 자동 상쇄됩니다.
- **자동 분류** : ① 내가 가르친 규칙(시트 `분류규칙`) → ② 기본 가맹점 사전(스타벅스·이마트 등) → ③ AI → ④ 기타. 확인 화면에서 분류를 고치면 **다음부터 기억**합니다.
- **수입** : `정기수입`(월급·연금·임대료…) / `비정기수입`(상여·중고거래·용돈…). 문자에 "급여/월급" 등이 있으면 정기로 추정합니다.
  시트의 **정기수입** 탭에 이름·금액·매월 N일을 적어 두면 매일 오전 9시 트리거가 해당 월에 **한 번만** 자동 등록합니다.
- **주간·월간 정산** : 시트의 `주간정산`/`월간정산` 탭 (정기수입·비정기수입·총지출·순수지·저축률 + 분류별 지출, 수입 vs 지출 차트). 앱 **정산** 탭에서도 같은 구성으로 봅니다.
- 시트의 `카테고리` 탭에서 분류를 추가/수정한 뒤 메뉴 **요약표 다시 만들기**를 누르면 정산표 열이 갱신됩니다.

### 문자·알림 완전 자동 (선택)
앱을 열지 않아도 결제 문자가 오면 시트에 저장되게 하려면, 폰 자동화 앱이 웹 앱 URL로 아래 요청을 보내게 합니다.

```
POST <웹 앱 URL>      Content-Type: text/plain
{"action":"ingest","token":"<토큰>","source":"자동전달","text":"<문자 내용>"}
```
- 안드로이드: MacroDroid/Tasker — 트리거 “SMS 수신(내용에 ‘승인’ 포함)” 또는 카드앱 “알림 수신” → HTTP 요청
- 아이폰: 단축어 → 자동화 → 메시지 → *URL 콘텐츠 가져오기*(POST, 요청 본문 JSON)

## 개인정보·보안

- 가계 데이터는 **내 구글 계정의 시트**와 **내 기기**에만 저장됩니다. 별도 서버·DB가 없습니다.
- 웹 앱은 토큰이 없으면 거부합니다. 토큰이 새면 Apps Script 속성 `TOKEN` 값을 바꾸고 앱에 다시 입력하세요.
- AI 인식을 켜면 **영수증 사진(최대 1400px로 축소)과 결제 문자 일부가 Anthropic API로 전송**됩니다. 끄려면 `ANTHROPIC_API_KEY` 속성을 지우세요(규칙 기반으로 계속 동작).

## 개발 / 테스트

```bash
node ledger/scripts/sync-core.mjs                                   # core/core.js 수정 후 복사본 갱신
node --test ledger/core/core.test.mjs ledger/apps-script/code.test.mjs   # 로직·백엔드(가짜 Google 서비스) 테스트
SHOTS=/tmp node ledger/scripts/e2e.mjs                              # 모바일 브라우저 E2E (Playwright)
```

## 알려진 한계

- 카드사별 문자 형식이 달라 가맹점 추출이 틀릴 수 있습니다 — 확인 화면에서 고치면 규칙으로 학습됩니다. 금액을 못 찾으면 AI 키가 있을 때 AI가 보완합니다.
- 앱에서 지운 내역은 시트에서도 지워지지만, **시트에서 직접 지운 내역은 앱에 남아 있습니다**(앱 데이터 삭제 후 “시트에서 불러오기”로 맞출 수 있음).
- 해외결제(외화 금액)는 원화 금액이 있는 문자만 인식합니다.
- Apps Script 호출은 환경에 따라 1~3초 걸립니다. 앱은 먼저 기기에 저장하고 뒤에서 전송합니다.
