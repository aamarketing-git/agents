# 리서치 1 · 고객관리가 필요한 직종과 영업 베스트프랙티스

## 1. 개인 고객관리 수요가 큰 직군 — 규모·현행 방식·페인포인트

**핵심 인사이트(보험):** 생보 전속설계사 평균 연령 **남 48.7세·여 51.8세**(2024), 60세 이상 약 20%로 최다 구간. 신규 유입 중 60대 비중 0.48%(2010)→10%(2024). 앱의 40~60대 타깃은 보험설계사 시장과 정확히 겹치며, 업계도 "고령화 대응 AI"를 공식 과제로 언급.

**우선순위:** ① 보험설계사(71만, 고령화, 페인포인트 명확) → ② 네트워크마케팅 실활동자(115만, 회사 앱 공백) → ③ 방판/렌탈·자동차 딜러 → ④ 중개사·미용/에스테틱(기존 도메인 앱과 보완).

## 2. 기존 국내 개인 CRM/영업관리 앱 — 기능과 평판

- **리멤버**: 명함 촬영→연락처, '리멤버 노트'(AI 녹음→요약·팔로업 체크리스트). 칭찬: "고객 히스토리 남기기 좋다". 불만: 채용·커뮤니티가 화면을 채움, 데이터 종속, 처리 지연.
- **세일즈맵**: B2B 파이프라인 CRM. 팀 대상이라 1인 영업인에게 과함.
- **보험설계사 전용(보케어·프로설계사·레몬브릿지·인스런)**: 청구·조회·만기알림 등 도메인 기능 중심. **상담 대화·개인 취향 기록, 자기계발 코칭은 거의 없음.**
- **범용 소상공인(김비서·고객관리 노트)**: "고객 정보가 메모장·카톡·사진에 흩어진다"는 문제를 다루지만 UI 구형.
- **공비서(뷰티)**: 업데이트 후 조작성 저하 불만 → **UI 변경에 민감한 사용자층**.
- **네트워크마케팅 회사 앱(암웨이·애터미)**: 쇼핑+실적. **파트너·소비자 개인 관리 기능 부재.**

**설계 원칙 도출:** 단순한 홈 화면 · 엑셀/연락처 내보내기 보장 · 카톡·문자 발송 원터치 · 즉시 반응 · 큰 글자 고정 레이아웃 · 홈 레이아웃과 핵심 버튼 위치 불변.

## 3. 영업 베스트프랙티스

**팔로업 횟수·끈기**
- "거래의 80%는 5회 이상 팔로업 후 성사, 영업인 44%는 1회 후 포기"(널리 인용되나 원출처 신뢰도 논란). 350만 리드 분석: 전환 리드의 93%가 6회 이내 통화 시도에서 접촉.
- 보험: 개인보험 성사까지 평균 **5~7회 접점**, 상업보험 7~12회. 효과적 시퀀스는 14~21일간 6~10회 접점.
- 한국 보험 현장: 생산성 저하 원인은 **AP(면담 약속) 실패**. 설계사 성과는 "계약자와의 월평균 교류 횟수"에 유의하게 영향(보험연구원).

**케이던스 룰**
- **2-2-2 룰**: 계약 후 2일·2주·2개월 연락(온보딩→습관→소개). 이탈 15~25% 감소 보고.
- **3-3-3 룰**: 최소 3회 접점, 3개 채널, 약 3일 간격.
- 미성사 리드는 3일·7일·30일 간격 리마인드가 케이던스 가이드들과 정합.
- **앱 반영:** 계약 직후 D+2/D+14/D+60 태스크 자동 생성, 미성사는 D+3/D+7/D+30, 채널(전화·카톡·방문) 교차 제안.

**개인 정보(취향·가족·기념일) 기억의 효과**
- 소비자 76%가 맞춤 커뮤니케이션이 브랜드 선택에 중요(McKinsey), 반대로 76%는 부정확한 개인정보 반영 시 부정적(Deloitte) → 기록 정확성이 곧 신뢰.
- 경험 자체보다 **경험에 대한 기억**이 충성 행동에 더 큼 → '만남 전 브리핑'이 유효.

**미팅 전 준비**
- 의사결정자 82%가 "영업인이 준비되어 있지 않다"고 평가, 상위 성과자 76%는 사전 조사 수행. 상위 성과자는 5회 접점으로 100명 중 52명을 미팅 전환(타 그룹의 2.7배).
- **앱 반영:** 일정 전 "고객 카드 요약 + 지난 대화 + 오늘 목표 + 예상 질문" 자동 브리핑.

**미팅 후 복기(디브리프)**
- 승패 분석 시 성사율 최대 50% 개선(Gartner), 그러나 1/3 미만만 수행.
- 망각곡선: 20분 후 58%, 24시간 후 33%만 기억. 회상 실패가 막연한 "안녕하신지요" 메시지로 퇴화.
- **앱 반영:** 미팅 종료 직후(≤20분) 음성 30초 디브리프 → AI가 사실/감정/다음 행동/개인 정보로 구조화.

## 4. 40~60대 음성 입력 사용성과 접근성

- AI 챗봇 이용률: 40대 18.7%, **50대 8.5%, 60대 3.4%**(KISDI). 50대는 인지 60.6%, 활용은 낮음.
- AI 스피커 이용률 60대 5.5%→**11.2%**(1년 만에 2배). 60대 이하 스마트폰 주5일 이용 90%+.
- 카카오톡 이용률 98.9%, 50·60대 3위 SNS는 밴드 → **카톡·문자·밴드 연동 필수**.
- 해외 50+ AI 이용 9%(2023)→30%(2025). 음성 선호 이유 "빠르다·타이핑 불필요". **음성이 텍스트 챗봇보다 고령층 진입장벽이 낮음.**
- 장벽은 '무엇을 말해야 할지 모름'과 오류 두려움 → 버튼 하나·예시 문장·오인식 즉시 수정·결과를 항상 텍스트로 재확인.

**접근성 수치**
- 글자 기본 16px 이상 + 사용자 확대 허용. 40대부터 시력 저하 시작.
- 터치 타깃: WCAG AAA 44×44px, Apple 44pt, Google 48dp, 간격 ≥8px. (본 앱: 60px 이상)
- 대비: 본문 4.5:1, 큰 글자·UI 3:1 이상.
- 구조: 1화면 1과업, 글꼴 1~2종, 홈 레이아웃 고정.

## 5. 제품 설계 시사점

1. 1차 타깃 **보험설계사(71만, 평균 50세)**, 2차 네트워크마케팅 실활동자(115만)와 렌탈·방판·자동차 딜러.
2. 기존 앱 공백 = **'사람 기억하기'**(개인 취향·가족·대화 맥락)와 **'행동 코칭'**. 도메인 기능(청구·매물·예약)은 기존 앱에 맡김.
3. 기본 루틴: 만남 전 브리핑 → 만남 후 20분 내 음성 디브리프 → 2-2-2/3-7-30 자동 태스크 → 카톡·문자 초안 생성.
4. UI: 큰 글자, 큰 버튼, 4.5:1 대비, 1화면 1과업, 음성 버튼 상시 노출 + 텍스트 확인, 내보내기 보장.
