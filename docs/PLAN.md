# 나의 커스텀 AI 비서 · 기획서 (v0.1)

> 손글씨 메모(2026-09-02)를 기본 구조로 하고, 사용자 요구 5가지와 리서치 2건(docs/RESEARCH_MARKET.md, docs/RESEARCH_MONETIZATION.md)을 반영했습니다.

## 1. 한 줄 정의
40~60대 개인 영업인이 **매일 아침 손안의 모바일로** 일정관리 → 고객관리 → 자기관리 → 성장 → 성공으로 가는 로드맵을 그려 주는, **내가 이름 지어 준 AI 비서**. 자비스처럼 곁에서 준비를 돕고, 만남을 기억하고, 영업 실적을 올리게 하는 시스템.

## 3. 사용자 요구사항 반영

1. **이름은 사용자가 지정** — 온보딩에서 직접 입력. 홈 히어로: "당신의 커스텀 AI 비서 ○○ 입니다." + 날짜별 격려 문장 + 오늘 일정·연락할 고객·성장 단계 요약으로 **만나기 전 자신감** 제공.
2. **컬러** — 보라 `#5B3FA6`(주색·신뢰), 초록 `#2F8F5B`(행동·성장), 아이보리 `#FBF8F1`(배경·편안함). `src/styles.css` 토큰으로 관리.
3. **40~60대 UX** — 기본 글자 18px(설정에서 20/23px), 버튼 최소 높이 60px, 대비 4.5:1 이상, 한 화면 한 과업, 접기/펼치기 버튼형(클릭하면 기능이 나타남), 하단 5탭 고정, 홈 레이아웃 고정. **기록은 타자 + 음성 받아쓰기** 동시 지원(모든 메모 입력창에 🎤 버튼).
4. **광고** — `AdSlot` 컴포넌트로 AdSense(웹) 연결, Capacitor 앱은 AdMob(docs/ADS.md). 리서치 결론에 따라 **콘텐츠 화면(교육센터·콘텐츠)에만 배치**, 고객 정보 화면에는 두지 않음. 프리미엄 사용자는 광고 없음.
5. **React, 웹·앱 최적화** — Vite + React 18 + React Router, PWA(홈 화면 설치·오프라인), 560px 중앙 카드 레이아웃으로 데스크톱 웹에서도 동일. Capacitor로 Android/iOS 래핑 가능.

## 4. 리서치 기반 핵심 설계 결정

- **1차 타깃: 보험설계사(71만 명, 평균 50세)**, 2차: 네트워크마케팅 실활동자(115만), 방판·렌탈·자동차 딜러. 직종 선택을 온보딩에 포함.
- **기존 앱의 공백 = "사람 기억하기"와 "행동 코칭"** → 고객 카드에 가족·건강·취미 필드, 만남 전 브리핑(④⑤), 만남 후 20분 내 음성 디브리프(⑥), AI 피드백(⑦).
- **팔로업 과학** → 관심도별 연락 주기 자동 계산, 오늘 연락할 고객 자동 추출, 2-2-2 법칙은 교육센터에서 학습.
- **AP(면담 약속) 실패가 실적 하락의 핵심** → 만남 기록 시 "다음 행동(언제·무엇)" 필수 유도, 감사 카톡 즉시 생성.
- **데이터는 내 것** → 로컬 저장, CSV 내보내기, JSON 백업·복원.

## 5. 수익모델 결정 (요약, 상세는 RESEARCH_MONETIZATION.md)

**결론: 구독 중심 프리미엄. 광고는 보조.**
- 광고 ARPU 상한 월 ₩500~1,500/명 vs 구독 ₩9,900. 니치 시장(활동 영업인 150~200만)에서는 유료 100명이 광고 MAU 1만과 맞먹음.
- CRM은 고객정보를 담는 도구 → 광고 SDK가 신뢰를 해침. 구독 앱 리텐션이 광고 앱의 2.6배.
- AdSense는 로그인 뒤 화면·대시보드 게재 금지 정책, AdMob은 PWA 미지원 → 기술·정책상으로도 "내부 화면 광고"는 부적합.
- 40~60대 구독 이용률 81~84%, 경쟁사(모홈) ₩9,900/₩39,600으로 시장 교육 완료.

| 플랜 | 가격 | 내용 |
|---|---|---|
| 무료 | 0 | 고객 50명, 일정·메모, AI 코칭 하루 5회, 콘텐츠 화면 광고 |
| 스탠다드 | 월 ₩9,900 / 연 ₩99,000 | 고객 무제한, AI 하루 30회, 광고 없음, 7~14일 체험 |
| 프로 | 월 ₩19,900~29,900 | AI 무제한(상위 모델), 대량 템플릿, 팀·리더 기능 |

단계: 0~6개월 PWA·광고 없음·랜딩/영업 노하우 블로그(SEO+AdSense 승인용) → 6~12개월 Capacitor 앱 출시 + 리워드 광고 "AI 5회 충전" → DAU 1만 이후 무료 티어 네이티브 광고 실험.

## 7. 기술 구조

- **프론트**: `app/` Vite + React 18 (JSX), React Router 6, 상태는 Context + localStorage (`src/store.jsx`). 백엔드 없이 완전 동작.
- **음성**: Web Speech API(ko-KR, 연속 인식) → 텍스트에 이어붙임. 미지원 브라우저 안내. (`src/lib/voice.js`)
- **AI**: `src/lib/ai.js` → `/api/coach`(서버 함수, `api/coach.js`, Anthropic SDK, 모델 `claude-opus-5`, 프롬프트 캐시, effort low). 서버 없으면 **규칙 기반 로컬 응답**으로 자동 대체(`src/lib/coaching.js`). API 키는 서버에만.
- **광고**: `src/components/AdSlot.jsx` (AdSense; 네이티브·프리미엄이면 미표시). `public/ads.txt`.
- **PWA**: vite-plugin-pwa, 매니페스트(보라 테마), 오프라인 캐시.
- **앱 래핑**: Capacitor(`npx cap add android/ios`) + `@capacitor-community/admob` (docs/ADS.md).
