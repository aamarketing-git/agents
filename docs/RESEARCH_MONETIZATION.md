# 리서치 2 · 수익모델 (광고 vs 무료·유료) 과 광고 기술·정책

> 작성일 2026-09-02. 환율 가정 ₩1,400/USD. 수치는 범위로 받아들이고 출시 후 실측으로 교체할 것을 전제로 합니다.

## 1. 시장 규모
- 보험설계사 **71.2만 명**, 다단계 등록 687만 중 활동 판매원 **약 115만 명**.
- "활동 중인 개인 영업인" 150만~200만 명의 니치 시장. **광고로 규모의 경제를 노리는 시장이 아니라 소수 유료 사용자에게서 높은 ARPU를 얻는 도구형 시장.**

## 2. 광고 vs 프리미엄 vs 구독

### 2-1. 한국 광고 단가 (2024~2026)
| 채널 | 형식 | 한국 eCPM/RPM 추정 |
|---|---|---|
| AdSense(웹) | 디스플레이 | Page RPM ₩1,500~10,000 (보수 $2 / 낙관 $5) |
| AdMob(앱) | 배너 | $1 미만 |
| AdMob(앱) | 전면 | 한국 iOS 약 $10 |
| AdMob(앱) | 리워드 | $10~11 |
| 카카오 애드핏 | 배너/네이티브 | 단가 비공개(체감상 애드센스 이하), 최소 지급 ₩50,000 |
| 네이버 애드포스트 | – | 네이버 내부 매체 전용, 외부 앱 불가 |

**이 앱에 대입한 광고 ARPU(1인/월):** 배너 약 ₩420 + 전면 약 ₩840 + 리워드 약 ₩460 → 현실적 상한 **월 ₩500~1,500/사용자**. MAU 1만 명이어도 월 500만~1,500만 원이 한계.

### 2-2. 무료→유료 전환율 벤치마크
- 프리미엄 셀프서브 SaaS **2~5%**, 상위 6~8%.
- 무료 체험(카드 등록 옵트아웃) 48~50%, 옵트인 17~18% → 프리미엄보다 훨씬 높음.
- 3% × ₩9,900 = 무료 사용자 1인당 월 ₩297 기대 매출. 숫자상 광고와 비슷해 보이지만 아래 이유로 구독이 우위.

### 2-3. CRM/생산성 앱이 광고를 피하는 이유
1. **ARPU 격차**: 광고형 앱 월 ARPU 보통 $2 미만, 구독 앱 $10 이상. 유료 1명 = 광고 사용자 10~20명.
2. **리텐션 격차**: 구독 앱 D30 리텐션 13.8% vs 광고 중심 앱 5.3%(2.6배). 광고 과다는 앱 삭제 이유의 15%.
3. **신뢰·데이터 민감성**: CRM은 고객 이름·연락처·계약 정보를 담는 기록 시스템. 광고 SDK는 기기 식별자·행동 데이터를 수집. 보험설계사는 대법원 2026.2 판결처럼 스스로 개인정보처리자로 취급될 수 있어 "내 고객 정보가 광고에 쓰이나?"라는 의심 자체가 치명적. 진성 하이브리드(구독+광고)는 전체 앱의 10%에 불과하며 광고 추가는 DAU 1만 이상부터 권장.

## 3. 40~60대 한국 사용자의 지불 의향과 가격대
- 성인 94.8% 구독 이용 경험. **50대 81%, 60대 84%**. 유료 OTT 50대 65%, 60대 이상 36%.
- 앱 정기결제 월평균 ₩13,317. 모바일금융 이용률 50대 약 90%, 60대 이상 53.8% → 결제 장벽은 크게 낮아짐.
- 단, **생성형 AI 유료 구독**은 60대 이상 5.3% → "AI 기능"이 아니라 **"고객 놓치지 않기·계약 성과"**를 팔아야 함.

| 서비스 | 가격 |
|---|---|
| 네이버플러스 멤버십 | 월 ₩4,900 |
| GoodNotes | 연 ₩14,000 |
| 노션 플러스 | 월 ₩16,800 |
| **모홈(보험설계사 영업지원)** | **프리미엄 월 ₩9,900(연 ₩99,000), 플러스 월 ₩39,600(AI 포함)** |
| 프로설계사 | 전 기능 무료 |

→ **월 ₩9,900 / 연 ₩99,000**은 이 직군에서 검증된 가격대. AI 상위 플랜은 ₩19,900~39,600까지 열려 있음.
- 스토어 수수료: Google Play 2026.12(한국) 구독 10%. **웹(PG 약 3%) 결제 우선**이 유리.

## 4. 기술·정책
### AdSense in React SPA
- 스크립트 1회 삽입 → `<ins class="adsbygoogle">` → 마운트 시 push. 라우트 변경 시 같은 요소에 재push하면 오류 → 라우트별 `key`로 재마운트.
- `public/ads.txt` 배치.
- **승인 리스크**: 크롤러가 JS를 실행하지 않아 SPA는 빈 페이지로 보임 → 승인용 정적 콘텐츠(영업 팁 블로그·랜딩) 필요.
- **정책**: 로그인 뒤 화면·대시보드·내비게이션 전용 화면에 광고 금지(Publisher Policies) → **CRM 내부 화면에 AdSense는 부적합. 교육센터 같은 콘텐츠 화면에만 가능.**

### AdMob in Capacitor
- **AdMob은 PWA 미지원**(네이티브 SDK 전용).
- `@capacitor-community/admob` v8: initialize → UMP 동의 → showBanner / prepareRewardVideoAd / showRewardVideoAd. Android Manifest `APPLICATION_ID`, iOS `GADApplicationIdentifier` 필요.
- 카카오 애드핏은 웹 스크립트 제공 → PWA에서 보조 채널 가능.

### LLM 비용 (1회 = 시스템 1,500토큰 캐시 + 컨텍스트 500 + 출력 200)
| 모델 | 10회/일(월) | 30회/일(월) |
|---|---|---|
| Claude Haiku 4.5 + 캐시 | ₩700 | ₩2,080 |
| Claude Sonnet 5 + 캐시 | ₩1,400 | ₩4,160 |
| Claude Opus 5 + 캐시 (추정, Sonnet의 약 2.5배) | 약 ₩3,500 | 약 ₩10,400 |
- 실제 무료 사용자 평균은 3~10회 → 무료 1인 월 원가 ₩100~700(경량 모델 기준).
- 리워드 광고 1회 ≈ ₩15 수익 → 경량 모델 호출 5~6회 원가 충당. **"광고 보고 AI 5회 충전"** 구조가 원가를 상쇄.

## 5. 권고: 구독 중심 프리미엄 + 광고는 옵트인 리워드와 콘텐츠 페이지에만

**순수 하이브리드(무료+상시 배너)는 채택하지 않음.** 프리미엄 구독을 주 수익원으로, 광고는 (a) 교육센터·영업 노하우 등 콘텐츠 화면의 AdSense, (b) 네이티브 앱 한정 옵트인 리워드 광고 두 곳에만.

**제안 요금 구조**
- **무료**: 고객 50명, 일정/메모, AI 코칭 일 5회. 한도 도달 시 업그레이드 안내. 리워드 광고 충전은 앱에서 사용자가 직접 누를 때만.
- **스탠다드 월 ₩9,900 / 연 ₩99,000**: 고객 무제한, AI 일 30회, 알림·리포트. **7~14일 체험(카드 등록 옵트인)**으로 전환율을 체험 구간(17%+)으로.
- **프로 월 ₩19,900~29,900**: AI 무제한(상위 모델), 카톡/문자 템플릿 대량 생성, 팀·리더 기능.
- 결제는 웹(PG) 우선, 앱은 스토어 결제 병행.

**단계별 실행**
1. 0~6개월(PWA): 광고 없음. 랜딩·영업 노하우 블로그 운영(SEO + AdSense 승인용 콘텐츠). 전환율·AI 사용량 실측.
2. 6~12개월(Capacitor 앱): 리워드 광고 1종만 "AI 충전" 옵트인. UMP 동의 + 개인정보처리방침에 광고 SDK 명시.
3. DAU 1만 이상: 무료 티어 한정 네이티브 광고 1자리 실험 여부를 데이터로 판단.

**KPI 가드레일**: 무료→유료 3% 미만이면 가격보다 온보딩(5분 내 첫 가치 경험)을 먼저 손볼 것.
