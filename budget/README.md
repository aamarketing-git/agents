# 찰칵 가계부

프리랜서와 일하는 주부를 위한 가계부. **찍거나 붙여 넣기만 하면 자동 분류되고, 기록은 내 구글 시트에 쌓입니다.**

- 결제 문자 자동 기록 (아이폰 단축어 / 안드로이드 자동화 앱 → 웹훅)
- 영수증 사진·쇼핑앱 주문 캡처·PDF → Claude가 가맹점·날짜·금액·**품목별 항목**까지 읽음
- 쿠팡·네이버페이·배달앱 주문 메일 자동 읽기 (선택)
- 같은 결제가 문자·캡처·메일로 여러 번 들어와도 **한 건으로 합침**
- 한 번 고친 분류는 ‘규칙’ 탭에 기억해 다음부터 자동 적용
- 한눈에: 일(달력) · 주 · 월 · 항목별, 수입 명세·지출 명세, 고정비/변동비
- 주간 리포트: 잘한 점 · 새는 곳 · 이번 주 미션, 프리랜서 ‘이번 달 써도 되는 돈’·세금 몫 떼어두기
- 종소세용 사업 수입·경비 CSV, 전체 CSV 내보내기

화면 설계: 디자인 캔버스의 ‘앱 화면 시안’ 보드.

## 구조

서버를 따로 두지 않고 **구글 시트에 붙은 Apps Script**가 앱이자 서버입니다. 데이터는 전부 사용자 본인의 시트·드라이브에 있습니다.

| 파일 | 역할 |
|---|---|
| `apps-script/Code.gs` | 시트 읽기·쓰기, 웹 앱(doGet)·웹훅(doPost), 앱이 부르는 `api*` 함수, 주문 메일 읽기 |
| `apps-script/Logic.gs` | 문자 해석, 자동 분류, 중복 찾기, 일·주·월 집계, 주간 리포트 (시트와 무관한 순수 로직) |
| `apps-script/Claude.gs` | 영수증·캡처·메일 → 구조화 JSON (Claude API) |
| `apps-script/Index.html` | 휴대폰 화면 (기록 · 한눈에 · 리포트 · 내 시트 · 첫 실행 안내) |
| `apps-script/appsscript.json` | 시간대(Asia/Seoul)·권한·웹 앱 설정 |

시트 탭: `원장`(거래 한 줄씩, 품목이 여럿이면 같은 `그룹`), `규칙`, `설정`, `요약-일/주/월/항목`(QUERY 자동 집계).

## 설치 (10분)

1. 구글 드라이브에서 새 **구글 시트**를 만들고 이름을 정합니다 (예: 우리집 가계부 2026).
2. 시트 메뉴 **확장 프로그램 → Apps Script**.
3. 편집기에 파일 5개를 만듭니다: `Code.gs`, `Logic.gs`, `Claude.gs`(스크립트), `Index`(HTML), 그리고 **프로젝트 설정 → ‘appsscript.json’ 매니페스트 파일 표시**를 켜고 `appsscript.json` 내용을 붙여 넣습니다. 각 파일은 이 폴더의 내용을 그대로 붙여 넣으세요.
   - clasp를 쓴다면: `clasp create --type sheets` 후 `apps-script/` 폴더를 `clasp push`.
4. **프로젝트 설정 → 스크립트 속성**에 `ANTHROPIC_API_KEY` = Anthropic API 키 (영수증·메일 읽기에 필요. 문자·한 줄 입력만 쓰면 없어도 됩니다).
5. 편집기에서 `setup` 함수를 한 번 실행 → 권한 허용. 원장·규칙·설정·요약 탭이 생깁니다.
6. **배포 → 새 배포 → 유형: 웹 앱**, 실행: **나**, 액세스: **모든 사용자** → 배포.
7. 시트를 새로고침하면 생기는 **가계부 → 앱 주소 보기** 메뉴의 주소를 휴대폰에서 열고 **홈 화면에 추가**.
   이 주소에는 비밀 키(`k=`)가 들어 있어 비밀번호처럼 다뤄야 합니다. 키가 없거나 틀리면 앱과 웹훅 모두 거절합니다.

권한 안내: 시트(현재 파일), 드라이브(영수증 사진·CSV 저장), 외부 요청(Claude API), 트리거(메일 읽기 주기), Gmail(주문 메일 읽기 — 설정에서 켰을 때만 실제로 읽음).

## 결제 문자 자동 기록

### 아이폰 (단축어)
1. 단축어 앱 → **자동화** → 새로운 자동화 → **메시지** → ‘메시지 포함’: `승인` → **즉시 실행**.
2. 동작 **URL 콘텐츠 가져오기**
   - URL: 앱 ‘내 시트 → 결제 문자 연결 안내’의 기록 주소 (`…/exec`)
   - 방법: POST, 요청 본문: JSON
   - `token`: 안내 화면의 token 값, `text`: 단축어 입력(메시지)
3. 입금 문자도 받으려면 ‘메시지 포함: `입금`’으로 하나 더.

### 안드로이드
- 가장 쉬운 방법: 결제 문자를 복사해 기록 탭 **한 줄로 기록**에 붙여 넣기 (문자 형식을 알아서 해석).
- 완전 자동: 문자 자동화 앱(예: MacroDroid)에서 ‘SMS 수신 → HTTP POST’, 주소와 본문은 위와 같음.

웹훅 형식: `POST {웹 앱 주소}` 본문 `{"token":"…","text":"결제 문자 전체"}` → `{"ok":true,"duplicate":false,…}`

## 개발

```bash
# 테스트 (순수 로직 + 가짜 구글 서비스 위에서 Code.gs 실행)
TZ=Asia/Seoul node --test budget/test/*.test.mjs

# 로컬 미리보기: 실제 Index.html + Code.gs, 예시 데이터, 가짜 영수증 인식
TZ=Asia/Seoul node budget/test/preview-server.mjs   # http://localhost:8787
SEED=0 …   # 빈 시트로 시작,  ONBOARD=1 …  # 첫 실행 안내부터
```

## 알려진 한계

- 카드사·은행마다 문자 형식이 달라 해석이 빗나갈 수 있습니다. 빗나간 문자는 ‘확인할 기록’에서 고치면 되고, 형식 예시를 알려주면 `Logic.gs`의 `parseBankSms`에 추가합니다.
- 아이폰은 다른 앱 알림을 읽을 수 없어 단축어 자동화(최초 1회 설정)가 필요합니다.
- Apps Script 웹 앱은 안드로이드 ‘공유하기’ 대상으로 등록할 수 없습니다 (붙여 넣기 또는 자동화 앱 사용).
- 영수증 읽기는 Claude API 사용료가 듭니다 (문자·한 줄 입력은 무료로 로컬 해석).
