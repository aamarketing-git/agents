# 🔮 나의 AI 사주 컴퍼니

사람은 대표(나) 한 명, 직원은 전부 AI인 1인 사주 웹서비스 회사를 픽셀 사무실로 보여 주는 **단일 HTML 파일**입니다.
고객 문의를 보내면 편지가 우편함 → 질문 담당들 → 업무 담당 책상으로 이동하고, 모든 판단은 내 컴퓨터의 로컬 AI(Ollama `POST /v1/systemone`)가 합니다.

## 실행
1. Ollama 0.35 이상 실행 → `ollama pull tev1:0.8b`
2. `saju-ai-company.html` 더블클릭
3. 브라우저가 막히면(CORS) `OLLAMA_ORIGINS="*"` 설정 후 Ollama 재시작

연결이 안 되면 앱이 해결 방법을 안내합니다. 체험 모드는 키워드 규칙이며 “체험 모드 · 실제 AI 아님”으로 크게 표시됩니다.
