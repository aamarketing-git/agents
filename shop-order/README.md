# 소상공인 주문·결제 시트앱 — 설치 안내

미네랄 주문서와 완전히 분리된 **새 앱**입니다. (새 스프레드시트 + 새 Apps Script + 새 사이트)

## 구성 파일
| 파일 | 역할 |
|---|---|
| `GoogleAppsScript.js` | 백엔드(구글 시트 저장, 토스 결제승인, 조회) |
| `index.html` | 주문서(상품선택 → 결제) |
| `success.html` | 결제 성공 → 승인·접수 완료 화면 |
| `fail.html` | 결제 실패/취소 화면 |
| `order-status.html` | 내 주문 조회(이름+전화) |

---

## 설치 순서

### 1. 구글 스프레드시트 + 백엔드
1. **새** 구글 스프레드시트 생성 (기존 미네랄 시트와 별개)
2. `확장 프로그램 > Apps Script` → 기본 코드 지우고 `GoogleAppsScript.js` 전체 붙여넣기 → 저장
3. 코드 상단 `TOSS_SECRET_KEY` 에 **토스 테스트 시크릿키**(`test_sk_...`) 입력
   - 토스페이먼츠 가입 → 개발자센터 → 내 개발정보 → **API 키 → "테스트" 탭 → 시크릿 키** 복사
4. `배포 > 새 배포 > 유형: 웹 앱`
   - 실행: **나**, 액세스 권한: **모든 사용자** → 배포
   - 생성된 `…/exec` URL 복사

### 2. 상품 등록
1. 스프레드시트 새로고침 → 상단 **📦 주문관리** 메뉴 생김
2. **📦 주문관리 > '상품설정 시트 만들기'** 클릭
3. `상품설정` 시트에서 상품명·단가 입력 (3~4개). 판매 안 할 상품은 `판매여부`를 `N`

### 3. 프론트(사이트) 연결
`index.html`, `success.html`, `order-status.html` 세 파일에서 맨 위 설정값 수정:
```js
var API_URL = '…/exec';                  // 1-4에서 복사한 배포 URL (3개 파일 모두 동일)
var TOSS_CLIENT_KEY = 'test_ck_...';     // index.html 만: 토스 테스트 '클라이언트 키'
var SHOP_NAME = 'OO상점';                // index.html / order-status.html: 상점 이름
```
> 클라이언트 키(`test_ck_`)와 시크릿 키(`test_sk_`)는 **다릅니다.**
> 클라이언트 키 = 화면용(index.html), 시크릿 키 = 서버용(Apps Script).

### 4. 배포(호스팅)
- Vercel 등에 `index.html / success.html / fail.html / order-status.html` 업로드
- 네 파일이 **같은 폴더**에 있어야 합니다 (성공/실패 리다이렉트가 같은 경로 기준으로 동작)

---

## 결제 흐름
1. 고객: 상품 수량 선택 + 정보 입력 → **결제하기**
2. 서버가 **상품설정 단가로 금액 재계산**(변조 방지) → 주문을 `결제대기`로 저장
3. 토스 결제창 → 성공 시 `success.html`
4. `success.html` → 서버가 토스 **결제 승인** → 주문 `결제완료`로 변경 + 영수증 저장
5. 고객은 `order-status.html`에서 이름+전화로 조회

## 테스트
- 테스트키 상태에서는 **실제 결제가 일어나지 않습니다.**
- 토스 테스트 카드번호로 결제 흐름 확인 가능(토스 문서 > 테스트 카드).

## 실제 결제로 전환할 때
1. 토스 심사 완료 후 **라이브 키**로 교체
   - `GoogleAppsScript.js` 의 `TOSS_SECRET_KEY` → `live_sk_...`
   - `index.html` 의 `TOSS_CLIENT_KEY` → `live_ck_...`
2. Apps Script **새 버전 재배포**, 프론트 재업로드

## 시트 구조
- **신규주문/완료**: 주문번호·일시·상태·주문자·연락처·받는분·주소·상품내역·총수량·총금액·결제수단·결제키·영수증URL·승인일시
- **상품설정**: 상품명·단가·설명·판매여부·정렬
- 결제완료 건은 **📦 주문관리 > '결제완료 주문 → 완료 이동'** 으로 정리 가능

## 참고
- 로그인(파이어베이스)은 이번 버전에서 제외 — 이름+전화로만 조회
- 나중에 매장별로 복제해서 쓰려면 스프레드시트·배포·키만 새로 만들면 됩니다
